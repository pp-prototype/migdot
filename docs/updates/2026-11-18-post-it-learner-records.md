- 관련 회의록 [저장 및 사용 흐름 설계](../meetings/2026-11-18-post-it-learner-product-design.md)

## 변경 사항

공통 로그인과 모듈 권한을 사용하는 개인 학습 공간을 추가했다. 주제 생성·수정, 포스트잇 작성·수정·삭제, 주제 및 기록 검색을 제공한다. 화면은 모바일 한 열 목록과 데스크톱 카드 그리드를 사용한다.

## 기술과 적용 조건

학습 주제와 기록은 별도 테이블에 저장한다. RLS는 모듈 이용 권한과 소유권을 확인하고, 복합 외래키는 다른 사용자 주제의 참조를 막는다. 버전이 달라진 경우 최신 내용을 보며 편집을 이어갈 수 있다. Supabase 설정이 없는 개발 서버에서는 예시 보드의 ‘기록 기능 체험하기’에서 같은 기록 화면을 체험한다. 체험 기록은 메모리에 저장하며 새로고침하면 초기화된다.

운영 연결에는 [학습 기록 마이그레이션](../../supabase/migrations/202611180001_learning_records.sql) 적용이 필요하다. 원격 프로젝트 적용과 실제 운영 백업 복원은 후속 확인 대상이다.

## 검증 결과

린트와 프로덕션 빌드가 통과했다. 로컬 PostgreSQL에서 계정 간 격리, 소유권 위조 방지, 모듈 권한 회수 및 버전 충돌을 검증했다. Chrome에서 개인 기록 저장·검색·수정·삭제, 응답 유실 뒤 중복 없는 재시도, 기존 개발 미리보기 흐름을 확인했다. 개인 기록 브라우저 테스트는 테스트 응답을 사용한다.

## 후속 화면과 첨부 변경

주제 카드의 이미지와 코르크 보드 배경을 복원했다. 주제 편집에서 등록한 썸네일은 480×270 JPEG로 잘라 압축한다. 용량을 제한한 썸네일만 주제와 같은 트랜잭션에 저장해 교체·제거를 처리한다. 기존 DB에는 썸네일 추가 마이그레이션을 적용해야 한다.

보드의 포스트잇과 첫 칸의 추가 카드를 정사각형으로 배치했다. 포스트잇에 사진 한 장을 첨부할 수 있으며 상세에서 사진 전체를 볼 수 있다. 운영 DB에 포스트잇 사진 마이그레이션을 적용해야 한다.

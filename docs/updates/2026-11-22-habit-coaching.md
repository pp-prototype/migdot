# 루틴 상세 기록 및 습관 제안

- 변경일 2026-11-22 (Asia/Seoul)
- 앱 버전 v0.1.0 · 커밋 전 작업
- 대상 실행 트래커 개인 클라우드 작업공간

오늘의 루틴에 상세 기록을 추가했다. 실제 실천 내용, 변화, 어려움을 메모하고 체감 난이도를 선택할 수 있다. 기존 빠른 체크에서 상세 기록을 추가하거나, 상세 기록을 저장하면서 실천을 완료할 수 있다. 날짜별 기록에 저장된 메모와 난이도를 표시한다.

루틴에 시작 신호와 가장 작은 실천을 설정할 수 있다. 최근 실천일과 난이도 응답을 사용해 작게 시작하기, 같은 신호에서 반복하기, 작게 다시 시작하기, 다음 단계 시도하기를 제안한다. 계획 변경 전 기록은 날짜별 이력과 실천일 수에 남는다. 단계 제안은 현재 계획에서 실천한 기록을 사용한다.

기존 데이터에 빈 선택 필드를 추가한다. 계정별 접근, 작업공간 리비전, 재시도 처리와 하루 마감 규칙을 기존 RPC에서 적용한다. 배포 전에 `202611220002_execution_habit_coaching.sql`을 순서대로 적용해야 한다.

검증 범위는 정적 검사와 빌드, SQL 접근 검사와 기존 명령, 브라우저에서의 상세 기록 저장·수정·복원·날짜별 조회, 계획 변경 및 난이도에 따른 제안 변화다.

# 익스큐셔너의 오늘 화면과 모바일 배치

- 변경일 2026-11-25 (Asia/Seoul)
- 대상 익스큐셔너
- 기록 커밋 `ba1eec4`

## 변경 사항

오늘 화면에서 과업 등록과 하루 마감을 상단에 배치하고, 캐릭터와 과업 현황을 짧은 요약으로 묶었다. 넓은 화면에서는 과업과 루틴을 나란히 두고, 좁은 화면에서는 과업을 먼저 보여주는 한 열로 배치한다. 주요 버튼에 텍스트를 표시하고 터치 영역을 44px 이상으로 유지했다.

## 적용한 디자인 기준

개발원칙서의 핵심 행동 우선, 읽을 수 있는 글자 크기, 화면 폭에 맞춘 목록 구성을 적용했다.

## 검증 결과

브라우저 테스트 9개를 통과했다. 320·390·768px에서 과업 등록 버튼과 과업 목록 제목이 첫 화면에 보이고 가로 넘침이 없는 것을 확인했다.

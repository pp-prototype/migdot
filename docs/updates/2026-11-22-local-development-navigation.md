# DB 없는 개발 모드와 앱 내비게이션

- 변경일 2026-11-22 (Asia/Seoul)
- 앱 버전 v0.1.0 · 커밋 전 작업
- 대상 공통 셸과 로컬 개발 환경

`npm run dev:local`을 추가했다. 개발 빌드의 local-preview 모드에서는 Supabase 환경 변수를 읽어 인증 클라이언트를 만들지 않는다. 예시 익스큐셔너에서 과업과 회고를 편집하고 고정 루틴을 체크할 수 있다. 작업 내용은 브라우저 메모리에 존재하며 새로고침하거나 모듈을 나가면 초기화된다.

기존 앱 내비게이션을 현재 개발 브랜치에 반영했다. 로그인 사용자는 권한을 받은 앱을, 로컬 체험 사용자는 체험 앱을 확인할 수 있다. 메뉴가 나타날 때 짧은 전환을 적용하고 모션 줄이기 설정을 지원한다.

검증 범위는 정적 검사, 빌드, DB 없는 체험에서의 임시 추가와 초기화, 앱 탐색, 인증 권한 및 로그아웃 뒤 메뉴 해제다.

# 결심 출격 관제실과 메카 합체 승인

- 변경일 2026-11-26 (Asia/Seoul)
- 대상 결심 출격 관제실

## 변경 사항

주제마다 확인 조건과 대기 시간을 설정한다. 기어를 잠그면 창작 메카가 단계별로 조립되고, 모든 조건이 잠기면 합체 완료 화면에서 출격을 승인할 수 있다. 지금 결정을 보류하고 격납고로 돌아가는 선택도 제공한다.

## 적용 조건

운영 DB에 모듈 등록 마이그레이션을 적용한다. 주제는 브라우저에 계정별로 보관하며, 잠금과 대기는 현재 세션에서 진행한다. [결심 출격 관제실 사용 안내](../documentations/resolve-launch/overview.md)

## 검증 결과

빌드와 브라우저 테스트 7개를 통과했다. 320px 화면에서 기어 드래그와 키보드 조작, 잠금 해제, 모든 조건을 확인한 뒤의 최종 승인, 대기 시간 및 격납고 복귀를 확인했다. 로컬 PostgreSQL에서 운영 모듈 등록 SQL을 실행해 등록 결과를 확인했다.

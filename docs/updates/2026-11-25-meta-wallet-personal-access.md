# 메타 월렛 모듈 권한과 계정별 지갑 저장

- 변경일 2026-11-25 (Asia/Seoul)
- 대상 메타 월렛과 공통 권한 관리
- 변경 커밋 `5f8802c`

## 변경 사항

메타 월렛을 모듈 권한 관리에 등록했다. 활성 운영자와 메타 월렛 이용 권한을 받은 일반 계정에 홈 카드와 앱 탭을 표시한다. 직접 접속에도 같은 권한이 적용된다.

## 적용 조건과 기존 기록

운영 Supabase에 `202611250001_meta_wallet_workspace.sql`을 적용해야 한다. 잔액, 돈 계획, 지출 일기는 계정별 지갑에 저장하며, DB는 모듈 이용 권한과 소유권을 함께 확인한다. 브라우저에 있던 이전 기록은 소유 계정을 확인할 수 없어 자동으로 옮기지 않았다. [메타 월렛 사용 안내](../documentations/meta-wallet/overview.md)

## 검증 결과

인증·허브 브라우저 테스트 19개와 로컬 DB 권한 검증을 통과했다. DB 테스트에서 타인 지갑 접근과 소유자 위조, 권한 회수 시 조회·수정 차단을 확인했다.

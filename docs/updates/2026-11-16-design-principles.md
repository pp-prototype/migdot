# 개발원칙서 v1.3 — 디자인 기준 추가

- 변경일: 2026-11-16 (Asia/Seoul)
- 문서 버전: 1.2 → 1.3
- 앱 버전: v0.1.0 유지 · 커밋 전 작업
- 대상: 개발원칙서 및 의사결정 기록

## 변경 사항

Readme.md에 원칙 11 ‘사용 목적에 맞는 일관된 디자인’을 추가했다. 국내 서비스별 분석과 근거, 허브 정보 구조와 경로, 색상·글자·카드 기준, 반응형 탐색, 접근성 및 브라우저 검증 기준을 포함한다. 원칙 3에서 새 디자인 기준을 참조하고, 설계 트리의 문서 원본 폴더 명칭을 현재 `documentations/`와 맞췄다.

## 사용자 경험·호환성

화면 코드나 라우팅 동작은 변경하지 않았다. 의사결정과 개정 기록은 기존 Markdown 문서 조회 방식에 포함된다. 개발원칙서의 공식 원본은 Readme.md로 유지한다.

## 검증

문서 버전·상태 일치, 원칙 11 구성과 원칙 3의 참조, 저장소 내 상대 링크의 대상 존재 및 공백 오류를 확인했다. 실행 코드를 변경하지 않아 앱 빌드나 브라우저 테스트는 재실행하지 않았다.

# 개발원칙서 v1.4 — 메타 월렛 UX 원칙 추가

- 변경일 2026-11-19 (Asia/Seoul)
- 문서 버전 1.3 → 1.4
- 대상 MIG DOT 공식 개발원칙서와 메타 월렛 모듈 문서

개발원칙서의 원칙 11에 메타 월렛 UX 기준을 추가했다. 모듈 문서에는 홈 구성, 점진적 설정, 하루 지출 일기, 날짜순 현금 흐름, 주간 돌아보기와 사용성 검증 기준을 기록했다. 현재 사용자 테스트에서 제공되는 동작과 후속 구현 범위를 함께 명시했다.

이번 개정은 문서에 적용했다. 원칙서의 버전과 상대 링크, 개정 문서의 제목과 위치를 확인했다.

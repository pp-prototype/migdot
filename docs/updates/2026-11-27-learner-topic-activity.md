# 포스트잇 러너 학습 주제별 개수와 최근 업로드 표시

- **변경일** 2026-11-27 (KST)
- **대상** 포스트잇 러너
- **버전** 0.1.0

학습 주제 카드 제목 오른쪽에 포스트잇 러너 기본 아이콘과 개수를 표시한다. 최근 업로드 날짜는 카드 하단에 표시하며 목록은 최신 업로드순으로 정렬한다. 포스트잇이 없는 주제는 목록 하단에 배치하며, 업로드 시각이 같은 주제는 기존 표시 순서를 따른다. 날짜는 브라우저 시간대를 기준으로 표시한다.

개인 기록 목록은 기존 소유자 접근 정책을 적용해 포스트잇의 소속 주제와 등록 시각을 조회한다. 주제별 개수와 최근 업로드 시각을 기존 기록에서 계산하므로 데이터베이스 마이그레이션 없이 적용할 수 있다. 예시 목록과 체험 목록에도 동일한 계산 규칙을 적용했다.

검증에서 린트와 프로덕션 빌드, Chrome의 포스트잇 러너 테스트 5건을 통과했다. 체험 목록의 등록 후 순서 변경, 인증 모의 환경의 삭제 후 카드 갱신, 320px 화면에서 목록의 가로 넘침 여부를 확인했다.

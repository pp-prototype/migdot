## 변경 사항

홈의 포스트잇 러너와 메타 월렛 카드에서 각각 ‘미리보기’와 ‘사용자 테스트’ 라벨을 제거했다. 홈 카드와 상단 ‘내 앱’ 메뉴는 같은 앱 목록을 사용하며, 공개 앱과 현재 계정이 접근할 수 있는 앱을 함께 표시한다. 좁은 모바일 화면에서 메뉴 링크는 줄바꿈된다.

기존 공개 앱의 독립 경로와 접근 권한이 필요한 앱의 권한 검사 경로를 유지한다. 브라우저 테스트에서 홈 카드와 메뉴의 일치, 작은 화면의 링크 노출, 로그인·권한 회수·로그아웃에 따른 메뉴 변경을 검증한다.

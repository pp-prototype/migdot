# 익스큐셔너 루틴 목표 및 실천 피드백

- 변경일 2026-11-22 (Asia/Seoul)
- 앱 버전 v0.1.0
- 대상 실행 트래커 개인 클라우드 작업공간
- 기록 커밋 `33e4176`

## 변경 사항

오늘 화면의 과업 목록 위에 루틴을 배치했다. 루틴 등록·수정에서 목표, 기대 결과, 최근 7일 중 목표 실천일 수를 설정한다. 카드에 당일 상태, 실천일 수, 진행 막대와 목표 달성 여부를 보여 준다. 목표에 도달할 때 저장 안내를 표시하고, 하루 마감 창에서는 당일 미기록 수를 표시한다.

## 기술과 적용 조건

Supabase 루틴에 목표, 기대 결과, 목표 실천일 수를 추가한다. 기존 루틴과 일별 기록을 유지하고 기존 루틴에는 7일 목표를 적용한다. 기존 클라이언트가 이름만 수정하는 요청도 이미 저장된 목표를 보존한다. 프런트엔드 배포 전에 `202611220001_execution_routine_goals.sql` 적용이 필요하다. 피드백은 앱 내부에 표시된다.

## 검증 범위

검증 범위는 정적 검사와 빌드, SQL 권한과 기존 명령, 브라우저에서의 등록·수정·기록·취소·복원·마감 안내, 최근 7일 집계 경계 및 모바일 가로 넘침이다.

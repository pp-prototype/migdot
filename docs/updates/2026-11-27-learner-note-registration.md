# 포스트잇 러너 포스트잇 등록 번호

- **변경일** 2026-11-27 (KST)
- **대상** 포스트잇 러너
- **버전** 0.1.0

포스트잇 오른쪽 위에 손글씨 느낌의 등록 번호를 넣고 상세 화면에서도 같은 번호를 표시한다. 번호는 주제별로 #1부터 부여하며 수정과 삭제 후에도 기존 번호를 유지한다. 삭제한 번호는 다시 쓰지 않는다.

Supabase 마이그레이션은 기존 포스트잇에 등록 시각과 ID 순서로 번호를 채운다. 새 포스트잇은 저장 시 데이터베이스 트리거가 주제별 다음 번호를 부여한다. 실제 개인 기록에 번호를 표시하려면 운영 Supabase에 마이그레이션을 적용해야 한다.

린트, 빌드, 데이터베이스 권한 테스트와 Chrome 테스트 5건을 통과했다. 기존 데이터에 번호를 채운 뒤 기록 버전이 유지되는 것도 확인했다.

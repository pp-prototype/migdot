# 익스큐셔너 기기 푸시와 예약 발송

- 변경일 2026-11-22 (Asia/Seoul)
- 앱 버전 v0.1.0 · 커밋 전 작업
- 대상 익스큐셔너, 웹 앱 설치, Supabase

알림 설정에 기기별 구독 등록과 해제를 연결했다. 홈 화면 설치 매니페스트와 수신 서비스 워커를 추가했다. 푸시는 남은 항목 수를 표시하며, 알림을 누르면 익스큐셔너의 오늘 화면을 연다.

한국 시간 오후 5시에는 기한이 오늘 또는 과거인 열린 과업을, 오후 9시에는 오늘 체크하지 않은 활성 루틴을 조회한다. 현재 권한이 있는 사용자에게만 발송하며 일자·기기·종류로 중복을 막는다. 실제 운영 연결은 새 마이그레이션, 발송 함수, 예약 실행, VAPID 환경설정을 적용한 뒤 수행한다.

검증 범위는 정적 검사와 빌드, SQL 권한·시간대·대상 조건·중복 방지, 브라우저의 구독·해제·서비스 워커 수신이다. 실제 휴대전화와 원격 예약 발송 검증은 운영 설정 적용 후 진행한다.

# 익스큐셔너 — 계획부터 하루 마감까지 체험

- 변경일 2026-11-16 (Asia/Seoul)
- 버전: v0.1.0 유지 · 커밋 전 작업
- 대상 실행 트래커, 모듈 오류 경계 유지 방식, 앱 표시 이름 및 사용 문서
- 기록 커밋 `8f2f7b0`

## 기능과 디자인

단순 읽기 전용 예시를 메모리 기반 상호작용 체험으로 확장했다. 과업 등록·수정·삭제, 첫 행동, 한 과업 실행 표시, 완료/취소, 일정 변경과 사유, 오늘로 복귀, 직전 변경 되돌리기, 루틴 실천·취소, 선택 회고와 하루 마감/재개를 제공한다.

후드와 망토를 입고 완료 도장을 든 자체 SVG 익스큐셔너를 작성했다. 대기·실행·축하·휴식 표정 및 대사, 종이색 장면, 세이지색 마감 패널과 조용한 완료 표시를 적용했다. 공통 메뉴·폰트·버튼 의미와 모바일 접근성을 유지한다.

## 기술과 호환성

상태를 모듈 루트에서 소유하고 오류 경계 키를 하위 주소 대신 모듈 ID로 두어 오늘/기록 전환 시 체험을 유지한다. 다른 모듈 이동 시에는 해제한다. 스타일은 CSS Modules로 격리한다. 의존성이나 클라우드 연결을 추가하지 않았다. 기존 경로 및 기록 선택 매개변수를 유지한다.

## 데이터와 제한

변경과 회고는 메모리에만 존재하며 새로고침·다른 모듈 이동 시 초기화된다. 실제 저장·인증·인가·집중 타이머·장기 분석은 미구현이다. 영구 저장 성공으로 표시하지 않는다. 일정 변경은 원래 날짜를 유지하고 완료와 별도 집계한다. 하루 마감은 미완료를 강제 완료하지 않는다.

## 검증

린트·타입 검사·프로덕션 빌드와 Chrome 브라우저 포함 테스트 11건이 통과했다. 과업 등록/수정/삭제, 실행/완료/되돌리기, 일정 변경/복귀, 루틴과 과업 진행률의 독립성, 미완료 마감/회고/재개, 모듈 내 상태 유지·새로고침 초기화, 저장소 불변·API 요청 없음과 기존 허브/학습 모듈 회귀를 검증했다. 320/390/768px 가로 넘침과 대화상자 첫 입력 포커스도 확인했다. 데스크톱 오늘 화면, 모바일 오늘·마감 화면을 육안 확인했으며 스크린샷은 `docs/previews/`에 저장했다.

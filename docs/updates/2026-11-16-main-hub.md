# 메인 허브와 문서별 라우팅

- 변경일 2026-11-16 (Asia/Seoul)
- 버전: v0.1.0 · 커밋 전 작업
- 대상 공통 앱 셸, 문서 모듈
- 상태 AI 작성 초안 · 개발자 검토 대기
- 기록 커밋 `0399549`

## 변경 사항

메인 `/`에 MIG DOT 제목과 모듈 앱 카드 목록을 표시한다. 상단 메뉴와 카드에서 회의록 `/meetings`, 개발업데이트 `/updates`, 문서 `/documentations`로 이동할 수 있다.

각 문서 페이지는 해당 Markdown 폴더의 목록·본문을 표시하고 검색 및 문서 선택 URL을 제공한다. 원본 `docs/documentation/`은 `docs/documentations/`로 이동했다.

## 호환성과 UX

기존 `/reports` 경로는 세 개의 문서별 경로로 대체되었다. 모바일에서도 네 개 메뉴를 탐색할 수 있도록 레이아웃을 조정했다. 인증이나 앱 데이터 저장 동작의 변경은 없다.

## 검증과 제약

ESLint, 타입 검사, 프로덕션 빌드가 통과했다. Playwright와 설치된 Google Chrome에서 데스크톱(1440×1000) 및 모바일(390×844) 브라우저 테스트 2건이 통과했다. 카드·메뉴 라우팅, 문서 렌더링, 선택 URL의 새로고침 유지, 검색·빈 결과, 404 페이지와 모바일 가로 넘침을 검증했다. 데스크톱 테스트에서 브라우저 실행·콘솔 오류는 없었다. 각 페이지 스크린샷은 `docs/previews/`에 저장했다. 초기 개발 서버의 오래된 최적화 캐시로 인한 504 오류는 `--force` 재시작으로 해소했다. favicon을 추가하고 재실행 가능한 `npm run test:ui` 명령을 구성했다. 개인용 기능 앱은 아직 이식하지 않았다.

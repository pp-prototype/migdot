# 개별 앱의 화면 구조와 모바일 작업 흐름 원칙

- 변경일 2026-11-25 (Asia/Seoul)
- 개발원칙서 1.4 → 1.5

공통 내비게이션 아래에서 앱을 시작하고, 앱 최상단에 로고와 이름을 표시한다. 앱 내부 탭은 상단에 배치하며 세부 표현은 실험한다. 앱 배경과 콘텐츠 너비를 구분하고, 모바일 기준의 콘텐츠 폭과 여백은 앱 간 비슷하게 맞춘다. 컴포넌트, 서체, 테마, 색상과 핵심 작업 영역은 각 앱의 성격을 드러낸다.

모바일에서는 첫 화면의 핵심 정보와 대표 행동, 빈 상태에서의 시작, 중단 후 재개를 검토한다. 구체적인 폭과 탭 표현은 세 앱의 시안을 비교해 결정한다. 이번 개정은 문서에 반영했다.

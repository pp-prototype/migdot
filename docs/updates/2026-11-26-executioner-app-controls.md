# 익스큐셔너의 앱 헤더와 작업 조작 개선

- 변경일 2026-11-26 (Asia/Seoul)

오늘과 기록 화면에 캐릭터 표식이 있는 앱 헤더를 적용했다. 공통 내비게이션 아래부터 다크 배경을 펼치고 콘텐츠 폭은 내부에서 제한했다.

집중 중인 과업을 우선 표시하고, 오늘 계획이 비어 있으면 이어온 과업부터 보여준다. 시작·완료·저장에는 라벨을 표시하고 보조 작업은 관리 버튼에 묶었다. 예정·보류 목록과 습관 제안 도움말에도 같은 펼침 동작을 적용했다. 기록 화면의 날짜 선택은 상시 표시하고 좁은 화면에서도 날짜 이동 버튼의 터치 영역을 유지한다.

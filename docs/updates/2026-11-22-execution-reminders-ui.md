# 익스큐셔너 알림 설정 화면

- 변경일 2026-11-22 (Asia/Seoul)
- 앱 버전 v0.1.0 · 커밋 전 작업
- 대상 실행 트래커

오늘과 기록 메뉴 옆에 알림 설정을 추가했다. 한국 시간 오후 5시 미완료 과업과 오후 9시 미기록 루틴의 알림 조건을 안내한다. iPhone·iPad와 Android 홈 화면 추가 방법을 펼쳐 볼 수 있다.

클라우드와 DB 없는 체험에서 같은 화면을 제공한다. 알림 켜기는 준비 중으로 표시하며 서비스 워커, 권한 요청과 예약 발송은 이후 연결한다. 체험 화면에서 설정을 둘러보고 돌아올 때 메모리 기록을 유지한다.

검증 범위는 정적 검사, 빌드, 클라우드·체험 메뉴 이동과 320px 화면이다.

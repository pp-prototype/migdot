## 변경 사항

알림 설정과 화면 개편을 병합한 뒤 오늘 화면에서 헤더와 탭이 중복 렌더링되고 밝은 바탕에 다크 테마용 글자가 표시됐다. 오늘·기록·알림 설정이 헤더와 탭을 공유하도록 정리하고 공통 내비게이션 아래의 다크 배경을 복구했다. 알림 구독과 예약 시각은 기존 설정을 사용한다.

## 검증 결과

브라우저 테스트 11개와 빌드, 로컬 DB 권한 검증을 통과했다. 440px을 포함한 모바일 화면의 헤더·탭 개수와 배경, 브라우저 푸시 구독과 해제를 확인했다. 운영 예약 발송과 실제 기기 수신은 [푸시 예약 발송 장애 복구 기록](../documentations/execution-tracker/push-cron-recovery.md)에서 추적한다.

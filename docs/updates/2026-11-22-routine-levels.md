# 루틴 첫 7일 레벨과 미니 익스큐셔너

- 변경일 2026-11-22 (Asia/Seoul)
- 앱 버전 v0.1.0 · 커밋 전 작업
- 대상 실행 트래커 개인 클라우드 작업공간

오늘의 루틴에 미니 익스큐셔너와 레벨을 표시한다. 기존 기록을 포함해 같은 루틴의 서로 다른 실천일에 1 XP씩 표시한다. 7일째 레벨 2가 되며 아이콘이 바뀌고 서버 저장이 확인되면 달성 안내가 나타난다. 실천 취소나 날짜 변경 후에도 저장된 날짜로 경험치와 레벨을 계산한다.

루틴 등록·수정에는 목표와 기대 결과, 시작 신호, 가장 작은 실천을 입력한다. 진행 목표 일수는 시스템의 7일을 사용한다. 습관 제안은 현재 계획에서의 실천과 체감 난이도로 결정한다. 레벨을 위한 추가 DB 마이그레이션은 없다. 기존의 루틴 목표와 상세 기록 마이그레이션을 적용한 작업공간에서 사용할 수 있다.

검증 범위는 정적 검사, 빌드, SQL 권한 및 저장 동작, 모바일 가로 넘침과 브라우저에서의 누적·레벨 상승·취소·복원, 상세 기록 재저장 시 XP 유지다.

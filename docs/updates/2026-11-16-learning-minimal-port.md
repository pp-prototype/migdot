# 포스트잇 러너 최소 이식 — 읽기 전용 미리보기

- 변경일: 2026-11-16 (Asia/Seoul)
- 앱 버전: v0.1.0 유지 · 커밋 전 작업
- 대상: 앱 등록, 메인, 포스트잇 러너 모듈

## 변경 사항

홈에 미리보기 앱을 등록하고 `/post-it-learner` 및 대상별 URL을 연결했다. 원본 f304de0에서 고정 예시, 보드 배치·페이지 계산과 기본 일러스트를 가져왔다. 화면은 TypeScript 및 CSS Modules로 구성하고 공통 셸 아래에서 지연 로딩한다.

학습 대상·기록 검색, 상세 다이얼로그, 선택 URL·새로고침·뒤로가기를 지원한다. 앱 등록과 기록 페이지를 구분하여 네 개 공통 메뉴를 유지한다. 미리보기와 예시 데이터임을 표시하며 개인 데이터 저장 기능은 제공하지 않는다. 추가 패키지 의존성은 없다.

## 호환성과 한계

원본 저장소는 변경하지 않았다. 기존 네 개 경로를 유지한다. localStorage 및 Supabase 저장·조회, 로그인, 생성·수정·삭제와 업로드는 연결하지 않았다. 코드 이식 완료는 운영 가능한 학습 앱이나 인증·클라우드 완성을 뜻하지 않는다. 겹친 보드의 최종 가독성·모바일 UX는 후속 검토 대상이다.

## 검증 결과

- ESLint, TypeScript 검사, 프로덕션 빌드 통과
- 허브 회귀 및 학습 모듈 테스트 총 6건 통과
- 검색·빈 결과·목록/보드 이동, 상세 URL과 새로고침, Escape 닫기, 뒤로가기 확인
- 잘못된 대상 주소, 공통 메뉴 복귀 및 모바일 가로 넘침 확인
- 학습 화면 탐색 전후 localStorage 불변 및 Supabase 요청 없음 확인
- 1000개 기록 페이지 계산에서 누락·중복 없이 최대 12장 표시 및 배치 좌표 범위 확인
- 데스크톱 목록 및 모바일 보드 스크린샷 육안 확인. 결과는 `docs/previews/learner*.png`에 저장

실제 클라우드와 개인 데이터는 이번 범위에 포함되지 않는다.

# 실행 트래커 최소 이식 — 읽기 전용 미리보기

- 변경일: 2026-11-16 (Asia/Seoul)
- 앱 버전: v0.1.0 유지 · 커밋 전 작업
- 대상: 앱 등록, 실행 트래커 모듈, 관련 문서와 브라우저 검증

## 변경 사항

홈에 두 번째 예시 앱을 등록했다. `/execution-tracker`에서 오늘의 필수 과업과 선택 루틴, 과업 기준 진행률을 표시하고 `/execution-tracker/records`에서 28일 루틴 수행과 날짜별 과업을 조회한다. 날짜·루틴 선택은 URL로 유지한다.

원본의 날짜 계산과 정보 구조를 참고해 TypeScript 및 CSS Modules로 구성했다. MIG DOT의 밝은 표면·녹색 강조와 공통 메뉴를 적용했다. 예시 기준일은 2026-11-16으로 고정하고 실제 오늘·개인 기록과 구분했다. 다른 모듈의 스타일이나 저장 동작은 바꾸지 않았다. 추가 패키지는 없다.

## 범위와 제한

원본 앱은 변경하지 않았다. 별도 서버·Google 로그인·SQLite·IndexedDB·서비스 워커와 PWA, 실제 기록 변경·집중 실행은 가져오지 않았다. 고정 예시 데이터를 조회할 수 있으며 운영 가능한 실행 관리 앱의 완성을 뜻하지 않는다.

## 검증

ESLint·타입 검사·프로덕션 빌드가 통과했다. 브라우저 포함 테스트 총 9건이 통과했다. 허브 및 학습 모듈 회귀, 과업/루틴 구분과 진행률, 날짜·루틴 선택 후 새로고침, 잘못된 날짜·빈 과업, 320/390/768px 가로 넘침, 공통 메뉴와 모듈 이동을 검증한다. 브라우저 저장소 불변과 API 요청 없음도 확인했다. 데스크톱 오늘 화면 및 모바일 기록 화면을 스크린샷으로 육안 확인했으며 `docs/previews/tracker-*.png`에 결과를 저장했다.

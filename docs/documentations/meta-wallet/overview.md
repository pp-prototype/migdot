# 메타 월렛 생활비와 돈 계획 사용 안내

메타 월렛은 오늘 쓸 수 있는 생활비를 확인하고, 기억나는 지출을 남기며, 상환·저축·지출 일정을 계획하는 개인 지갑입니다. 로그인 후 메타 월렛 이용 권한이 있어야 열 수 있습니다.

## 홈과 지출 일기

1. **잔액 입력**에서 지금 바로 쓸 수 있는 돈을 입력합니다.
2. 다음 입금일을 정합니다. 날짜를 모르면 **날짜를 모르겠어요**를 눌러 생활해야 할 일수를 입력합니다.
3. **오늘 생활비**는 확인 잔액과 입력한 예정 입출금으로 계산합니다. **오늘 쓴 돈**에는 금액이나 메모만 남겨도 됩니다. 정확하지 않은 금액은 대략적인 금액으로 표시할 수 있습니다.
4. **지출 일기**에서 날짜를 선택해 해당 기록을 조회하거나 수정합니다. 최근 7일 보기에서 기록 없음, 0원, 메모만 남긴 날을 각각 확인할 수 있습니다.

## 돈주머니와 예정 입출금

1. **돈 계획**에서 **갚을 돈**, **모을 돈**, **써야 할 돈**을 확인합니다. 생활 기간이 설정된 경우 오늘부터 마지막 생활일까지의 예정액을 표시합니다. 기간을 정하기 전에는 남은 예정액 전체를 표시합니다.
2. 항목을 열어 내역을 보거나 **상환 추가**, **저축 추가**, **지출 추가**를 선택합니다. 이름·금액·날짜를 입력하고, 연결할 수 있는 기존 부채나 저축 계좌가 있으면 선택합니다.
3. 반영 전 오늘 생활비와 예상 부족액을 확인하고 **돈 계획에 반영**을 누릅니다. 입금 예정은 **예정 입출금**에서 추가합니다.
4. 실제 입출금이 끝나면 **처리 확인**에서 처리 후 확인한 잔액을 입력합니다. 처리한 일정은 앞으로의 예상 입출금에서 빠집니다.

남은 부채 총액과 저축 목표액은 각 계좌에서 확인합니다. 돈주머니의 예정액과 오늘 생활비는 기준이 다릅니다. 생활비 계산에는 생활 기간 뒤에 입력된 일정도 반영합니다. [메타 월렛 개발·디자인 원칙](principles.md)

## 저장과 문제 해결

- 개인 지갑은 로그인한 계정에 저장됩니다. 예시로 둘러보기의 입력은 예시 지갑에만 반영됩니다. **내 지갑으로 돌아가기**를 누르면 개인 기록을 다시 봅니다.
- 저장 요청이 실패하면 입력을 유지한 상태에서 **저장 다시 시도**를 누릅니다. 다른 기기의 변경과 충돌하면 **최신 지갑 불러오기** 후 입력과 계산 결과를 다시 확인합니다.
- 홈에 메타 월렛이 없으면 현재 계정의 앱 권한과 서버 설정을 확인합니다. [MIG DOT 로그인과 모듈 이용 권한](../mig-dot/login-and-access.md)

# 스틸라 단어장과 복습 사용 안내

스틸라는 내가 만난 단어와 문장을 담고, 뜻과 문장 속 표현을 떠올려 보는 어학 앱입니다.

## 단어와 예문 담기

1. **단어 담기**에서 학습 언어를 정하고 표에 원어, 발음, 뜻, 비고를 입력합니다. 원어만 필수입니다. Tab으로 다음 칸, Shift+Tab으로 이전 칸에 이동합니다. 마지막 줄에 입력하면 새 줄이 생깁니다. 스프레드시트에서 복사한 행은 원어 칸에 붙여넣습니다. 두 열은 원어와 뜻으로, 네 열은 원어·발음·뜻·비고 순서로 가져옵니다.
2. 저장 전에 신규와 중복 수를 확인합니다. 같은 언어의 중복 단어는 건너뛰며 기존 기록이 이어집니다.
3. 단어장에서 원어·발음·뜻·비고·언어로 검색하고 단어를 엽니다. **단어 수정**에서 원어, 학습 언어, 발음, 뜻, 비고를 변경할 수 있습니다. **예문 연결**에서 새 문장을 적거나 앞서 저장한 문장을 골라 연결합니다.
4. 빈칸 복습을 하려면 문장에 나온 표현을 그대로 입력합니다. 표현이 여러 번 나오면 가릴 위치를 고릅니다.

## 문장부터 담고 단어 연결하기

1. **문장**에서 원문과 학습 언어를 입력합니다. 해석도 기록하면 문장 해석 문제로 연습할 수 있습니다.
2. 같은 언어의 단어장에서 관련 단어를 골라 연결합니다. 없는 단어는 새 단어를 적고 발음, 뜻, 비고를 필요한 만큼 채운 다음 **새 단어 담기**를 누릅니다.
3. **문장 저장**을 누르면 문장, 새 단어, 단어 연결을 함께 저장합니다. 담은 문장 목록에서 연결된 단어를 열 수 있습니다.

## 단어 삭제

단어 상세에서 **단어 삭제**를 누른 뒤 확인합니다. 이 단어의 연결과 뜻·빈칸 복습 기록이 함께 삭제됩니다. 예문 원문은 보관되므로 다른 단어에서 계속 보거나 다시 연결할 수 있습니다.

## 복습하고 이어가기

복습 화면에서 한 번에 최대 5장씩 시작합니다. 답을 입력하거나 머릿속으로 떠올리고 **답 보기**를 누릅니다. 뜻과 문장 빈칸은 각각의 카드로 복습합니다. **다시**를 고른 카드는 10분 뒤, **기억함**을 고른 카드는 24시간 뒤 복습 대상에 들어옵니다. 중간에 다른 화면으로 이동하거나 다음에 앱을 열면 저장한 카드 위치부터 이어갑니다.

**무작위로 공부하기**를 누르면 복습 시점과 관계없이 단어 뜻, 문장 빈칸, 문장 해석 중 최대 5문제를 섞어서 출제합니다. 단어 뜻이나 문장 해석을 입력한 경우 저장한 답과 겹치는 표현을 보여줍니다. 표현이 달라도 뜻이 같을 수 있으므로 최종 결과는 **다시** 또는 **기억함**으로 직접 기록합니다.

## 플래시카드

**플래시카드** 탭에서 복습할 범위와 카드 유형을 고르면 최대 5장을 섞어 보여줍니다. 기존 단어 뜻, 문장 해석, 빈칸으로 카드가 만들어집니다. 앞면에서 답을 떠올린 뒤 카드를 누르거나 Space 키로 뒤집습니다.

기억한 정도에 따라 **다시**는 10분, **어려움**은 6시간, **기억함**은 1일, **쉬움**은 4일 뒤 복습 대상으로 돌아옵니다. 답을 연 뒤 숫자 1–4로도 기록할 수 있습니다. 이 간격은 선택마다 고정이며 입력형 복습과 같은 복습 기록을 사용합니다. 플래시카드 진행 위치는 입력형 복습과 별도로 저장합니다.

## 저장과 접근

운영 환경에서는 공통 로그인과 스틸라 이용 권한이 필요합니다. 단어와 예문, 복습 결과는 사용자별 Supabase 작업공간에 저장합니다. 저장에 실패하면 열린 입력 양식에서 내용을 확인하고 다시 시도할 수 있습니다. 다른 기기에서 작업공간을 먼저 수정했을 때는 새 기록을 불러오므로 확인 후 다시 저장합니다.

로컬 개발 체험에서는 새로고침하면 작성한 기록이 초기화됩니다.

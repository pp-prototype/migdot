# 실행 트래커 — 과업과 루틴 미리보기

## 개요

오늘 끝낼 필수 과업과 할수록 좋은 선택 루틴을 구분하고, 날짜별 예시 기록을 살펴보는 읽기 전용 모듈입니다. 실제 사용자 데이터가 아니며 모든 예시는 2026-11-16을 기준으로 고정되어 있습니다.

## 제공 기능과 사용 방법

1. 메인의 내 앱에서 ‘실행 트래커 · 미리보기’를 선택합니다.
2. 오늘 화면에서 필수 과업의 완료/전체 수와 남은 수를 확인합니다. 선택 루틴은 과업 진행률에 포함하지 않습니다.
3. 모듈 상단의 ‘기록’ 또는 ‘루틴 기록 살펴보기’를 선택합니다.
4. 루틴을 선택해 최근 28일 실천 여부를 확인합니다. 셀의 날짜를 누르거나 날짜 입력·이전/다음 버튼으로 해당 날짜의 과업을 조회합니다.
5. ‘기준일’ 버튼은 실제 오늘이 아닌 예시 기준일로 돌아갑니다.

미실천은 ‘기록 없음’으로 표시하고 생성 전 날짜는 비활성화합니다. 셀을 선택해도 수행 기록은 변경되지 않습니다. 28일 실천 일수는 조회한 예시 기간의 기록 수이며 전체 일수를 대상으로 한 달성률은 아닙니다.

## 경로와 선택 상태

- `/execution-tracker`: 오늘의 예시 과업과 루틴
- `/execution-tracker/records`: 최근 28일 수행 기록과 날짜별 과업
- 기록 페이지의 `date`와 `routine` URL 매개변수로 선택을 유지합니다.
- 지원 날짜는 예시 기준일을 포함한 28일입니다. 잘못된 날짜·범위 밖 날짜는 기준일로, 알 수 없는 루틴은 첫 루틴으로 표시합니다.

## 데이터와 제한

별도 설정 없이 예시 데이터를 표시합니다. 개인 데이터, localStorage, IndexedDB 및 Supabase를 읽거나 변경하지 않습니다. 저장 기능, 실제 완료·취소·되돌리기, 과업·루틴 작성, 집중 타이머, 로그인, 오프라인 기록, 백업·이관은 제공하지 않습니다. 실제 운영 기능은 공통 인증·인가와 단일 Supabase 기준으로 후속 구현합니다.

기존 앱의 게임 테마와 독립 하단 메뉴 대신 MIG DOT 공통 스타일과 네 개 메뉴를 사용합니다. 모듈 내부 ‘오늘/기록’은 본문 상단에서 이동합니다.

# 익스큐셔너 — 하루 집행록 체험

## 개요

작은 과업에도 진지한 귀여운 집행관과 하루를 계획하고, 실행하고, 정리하는 체험 모듈입니다. 예시 기준일은 2026-11-16입니다. 처음에는 예시 과업과 루틴이 표시됩니다.

**변경 내용은 서버나 브라우저 저장소에 저장하지 않습니다. 새로고침하거나 다른 모듈로 이동하면 초기화됩니다. 개인 기록을 영구 보관하는 용도로 사용하지 마세요.** 오늘과 기록 사이를 이동할 때는 체험 상태를 유지합니다.

## 오늘의 과업

1. 메인에서 ‘익스큐셔너 · 실행 트래커’를 엽니다.
2. ‘과업 등록’을 눌러 이름과 선택적인 ‘첫 행동’을 입력합니다.
3. ‘시작하기’로 지금 실행할 과업을 고릅니다. 한 번에 한 과업만 실행 중으로 표시하며 익스큐셔너의 표정과 대사가 반응합니다.
4. 번호 버튼을 눌러 완료하거나 완료를 취소합니다. ‘시작하기’는 타이머를 실행하지 않습니다.
5. ‘수정’에서 과업 이름·첫 행동을 바꾸거나 삭제합니다.
6. ‘일정 조정’에서 다음 실행 날짜와 이유를 선택합니다. 원래 예정일은 메모리에 유지되며 일정 변경을 완료로 계산하지 않습니다. 아래 ‘다시 배치한 과업’에서 오늘로 되돌릴 수 있습니다.

변경 뒤 알림의 ‘되돌리기’로 직전 상태를 복구합니다. 이 알림은 오늘 화면을 벗어나면 사라집니다. 일정 조정된 과업은 기준일 진행률의 대상에서 제외되고 조정 개수로 따로 표시합니다.

## 작은 실천과 관찰

루틴 버튼으로 기준일의 실천을 기록·취소할 수 있습니다. 루틴은 선택적 실천이므로 필수 과업 진행률에 영향을 주지 않습니다. 현재 루틴의 등록·수정·삭제는 제공하지 않습니다.

‘오늘의 나를 읽는 법’은 이번 체험의 완료·남은 과업·일정 조정 수와 선택한 과업을 보여줍니다. 심리 상태나 성격을 판정하거나 AI 분석을 수행하지 않습니다.

## 하루 마감

과업이 남아 있어도 ‘하루 마감하기’를 선택할 수 있습니다. ‘오늘 알게 된 것’과 ‘내일의 첫 행동’은 선택 입력입니다. 마감하면 회고와 오늘의 상태를 보여주고 익스큐셔너는 쉬는 모습으로 바뀝니다.

마감은 미완료 과업을 자동 완료하거나 다른 날짜로 옮기지 않습니다. ‘마감 다시 열기’로 과업 화면에 돌아올 수 있습니다. 회고와 내일의 첫 행동 역시 체험 중인 메모리에서만 유지됩니다.

## 기록 조회와 경로

- `/execution-tracker`: 과업·실천·캐릭터·마감 체험
- `/execution-tracker/records`: 최근 28일 루틴과 날짜별 과업 조회
- 기록 페이지의 `date`와 `routine` 매개변수로 선택을 유지합니다.

루틴을 선택하고 날짜 셀 또는 날짜 입력·이전/다음 버튼으로 과업을 조회합니다. 기준일의 루틴과 과업은 현재 체험 변경을 반영합니다. 과거 날짜의 기록은 고정 예시입니다. 일정 조정으로 기준일 이후에 배치한 과업은 오늘 화면의 조정 목록에서 확인합니다.

실천하지 않은 날짜는 ‘기록 없음’이며, 생성 전 날짜는 비활성화합니다. ‘기준일’은 실제 오늘이 아닌 예시 날짜로 돌아갑니다. 잘못된 날짜·범위 밖 날짜는 기준일로, 알 수 없는 루틴은 첫 루틴으로 표시합니다.

## 제공하지 않는 기능

공통 로그인·인가, Supabase 저장·동기화, 실제 집중 타이머·집중 이력, 오프라인 저장, 알림·PWA, 백업·이관은 아직 연결하지 않았습니다. 내일의 첫 행동을 입력해도 새 과업을 자동 생성하지 않습니다. 레벨·상점·재화·벌점과 출석 보상도 없습니다.

## 디자인과 접근성

공통 메뉴와 홈 이동은 MIG DOT를 따릅니다. 후드 집행관과 완료 도장, 종이색 장면·세이지색 마감 패널로 모듈 정체성을 표현합니다. 상태는 대사와 라벨로도 확인할 수 있고 키보드로 주요 버튼과 대화상자를 조작할 수 있습니다. 모션 감소 설정에서는 캐릭터의 움직임을 끕니다.

# 익스큐셔너 — 나의 하루 집행록

## 시작과 저장

로그인하고 실행 트래커 이용 권한을 받은 사용자는 자신의 과업·루틴·회고를 Supabase에 저장합니다. 신규 계정은 빈 목록에서 시작합니다. 운영자도 다른 사용자의 개인 기록을 조회할 수 없습니다. 최초 운영 설정에는 `202611170002_executioner_workspace.sql` 마이그레이션이 필요합니다.

날짜는 한국 시간(Asia/Seoul) 기준입니다. ‘시작하기’는 집중할 과업 하나를 선택하는 기능이며 시간을 측정하지 않습니다. 서버 저장을 확인한 뒤 목록·완료 반응을 갱신합니다. 새로고침·모듈 이동·다른 기기 로그인 후 저장된 기록을 다시 불러옵니다. 화면 복귀와 분 단위로 최신 기록을 확인하며 실시간 동시 편집은 제공하지 않습니다.

## 과업과 자동 이월

1. ‘과업 등록’에서 이름과 계획 날짜를 입력합니다. 첫 행동은 선택입니다. 과거 날짜의 새 과업 등록은 허용하지 않습니다.
2. ‘시작하기’로 집중 대상을 고르고 ‘완료’로 실제 완료를 기록합니다. 완료 취소도 가능합니다.
3. 미완료 과업은 다음 날 ‘이전부터 이어온 과업’에 자동 표시됩니다. 앱에 접속하지 않거나 하루를 마감하지 않아도 동일한 과업 하나를 이어 보여줍니다. 날짜별 복제나 상시 배치 작업은 없습니다.
4. 최초 계획일, 현재 일정, 각각의 경과 일수와 직접 일정 변경 횟수를 구분합니다. 접속하지 않은 기간을 사용자가 직접 미룬 횟수로 해석하지 않습니다.
5. ‘일정 조정’으로 미래 날짜를 정하면 그 날짜 전에는 자동 이월하지 않습니다. 최초 계획과 이전 변경 기록은 남습니다.
6. ‘보류’는 자동 이월에서 제외합니다. ‘예정·보류한 과업’을 열어 ‘오늘로 복귀’할 수 있습니다.
7. ‘과업 취소’는 확인 후 활성 목록에서 제외하며 완료로 계산하지 않습니다. 과거 계획과 취소 이력은 남습니다. 영구 삭제 기능은 아닙니다.

‘오늘 계획한 과업’은 현재 일정이 오늘인 미완료, ‘이전부터 이어온 과업’은 현재 일정이 과거인 미완료, ‘오늘 완료한 과업’은 실제 오늘 완료한 기록입니다. 과업 수는 작업량이나 생산성 점수가 아닙니다.

## 루틴

루틴 이름을 등록·수정하고 오늘의 실천을 기록·취소할 수 있습니다. 미실천은 다음 날로 이월하지 않으며 과업 완료율에도 포함하지 않습니다. 중단할 루틴은 ‘보관’하면 과거 실천 기록을 유지합니다. 기록 화면은 보관한 루틴도 표시합니다. 첫 버전에서는 과거 날짜 실천 수정·보관 복귀·반복 요일 설정을 제공하지 않습니다.

## 하루 마감과 회고

미완료가 있어도 ‘하루 마감하기’를 선택합니다. ‘오늘 알게 된 것’과 ‘내일의 첫 행동’은 선택 입력입니다. 마감은 미완료를 완료로 바꾸지 않으며, 다음 날 자동 이월을 막지 않습니다. 내일의 첫 행동은 메모이고 과업을 자동 생성하지 않습니다.

마감 중 오늘 과업·루틴 변경을 잠급니다. ‘마감 다시 열기’ 후 수정하고 다시 마감할 수 있습니다. `/execution-tracker/records`에서 과거 날짜의 회고도 다시 열어 수정할 수 있습니다. 과거 회고 수정은 실제 과업 완료 시각을 소급 변경하지 않습니다.

## 날짜별 기록

기록 화면에서 날짜를 선택하면 당시 대상·당일 완료·다음 날로 이어짐·일정 조정을 확인합니다. 보류·취소도 상태로 표시합니다. 통계는 당시 과업 변경 이력을 기준으로 계산합니다. 월요일 미완료를 화요일에 완료하면 월요일 당일 완료 수는 증가하지 않고 ‘이후 화요일 완료’가 별도로 표시됩니다.

## 연결 실패와 동시 수정

오프라인 저장은 제공하지 않습니다. 편집 중 연결이 끊기거나 저장 응답을 확인하지 못하면 입력 창을 유지하고 추가 저장을 잠급니다. ‘최신 기록 불러오기’로 반영 여부를 확인한 뒤 진행하세요. 탭을 닫거나 새로고침하면 아직 저장되지 않은 입력은 사라집니다.

다른 기기가 먼저 수정한 경우 덮어쓰지 않고 충돌을 알립니다. 최신 기록을 확인하고 필요하면 다시 수정합니다. 동일 요청 재전송은 중복 처리하지 않습니다. 최신 기록을 불러오는 시점에는 기존 화면 내용도 갱신되므로 내용을 확인하세요.

## 캐릭터와 범위

귀여운 집행관은 집중·완료·마감 상태에 반응합니다. 경과 기간은 사실로 안내하며 벌점·심리 판정·성격 분석을 하지 않습니다. 재화·레벨·상점·타이머·알림·오프라인 큐·기존 앱 데이터 이관은 제공하지 않습니다.

Supabase 설정이 전혀 없는 개발 서버는 기존 고정 날짜의 메모리 체험을 유지합니다. 체험 데이터는 실제 계정으로 자동 이전하지 않습니다. 배포 환경에는 체험 권한을 부여하지 않습니다. 실제 개인 기록을 체험 화면에 입력하지 마세요.

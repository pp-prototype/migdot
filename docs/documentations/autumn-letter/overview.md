# 가을 편지 입장과 진행 기록 안내

가을 편지는 별도 링크로 여는 웹 체험입니다. 초대받은 사용자는 전달받은 입장 코드를 입력하고 화면의 안내에 따라 진행합니다.

## 입장과 다시 열기

[`/autumn-letter`](/autumn-letter)에서 네 자리 코드를 입력합니다. 같은 브라우저에서 다시 열면 저장된 진행 상태로 이어집니다.

## 진행 기록과 문제 해결

진행 기록은 현재 브라우저 저장소에 있습니다. 다른 브라우저나 기기에서는 진행 상태가 이어지지 않습니다. 이전 진행이 보이지 않으면 먼저 이용하던 브라우저 프로필과 주소를 확인합니다. 입장 코드는 전달받은 코드를 입력해 체험을 여는 데 사용됩니다.

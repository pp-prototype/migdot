# 포스트잇 러너 — 최소 이식 미리보기

## 제공 범위

기존 로컬 프로젝트의 학습 대상 → 코르크 보드 → 포스트잇 상세 흐름을 MIG DOT에서 확인하는 읽기 전용 미리보기입니다. 개인 데이터나 완성된 클라우드 앱이 아닙니다.

- 학습 대상 3개와 포스트잇 6개의 고정 예시
- 학습 대상 이름·설명 검색
- 보드 기록 제목·본문·태그 검색
- 포스트잇 상세 다이얼로그
- URL에 학습 대상, 검색어, 보드 페이지와 상세 기록 선택 유지
- 한 보드에 최대 12장을 표시하는 페이지 계산
- 공통 메뉴 및 MIG DOT 메인 이동

## 사용 방법

1. 메인의 내 앱에서 ‘포스트잇 러너 · 미리보기’를 선택합니다.
2. 학습 대상을 선택해 보드를 엽니다.
3. 포스트잇을 누르면 상세 본문이 열립니다. 닫기 버튼, Escape 또는 배경을 눌러 닫습니다.
4. ‘학습 대상 목록’으로 돌아가거나 공통 메뉴로 다른 페이지를 엽니다.

기본 경로는 `/post-it-learner`, 대상별 경로는 `/post-it-learner/topics/<대상ID>`입니다. 검색은 `q`, 보드 페이지는 `page`(0부터), 상세 기록은 `note` 매개변수를 사용합니다. 주소로 직접 접속하거나 새로고침해도 선택한 화면이 유지됩니다.

## 데이터와 제약

미리보기는 소스에 있는 예시만 사용합니다. localStorage를 읽거나 쓰지 않고 Supabase 요청도 하지 않습니다. 별도 환경 변수 설정은 필요하지 않습니다.

생성·수정·삭제, 사진 업로드, 로그인, 저장·동기화, 내보내기·가져오기는 제공하지 않습니다. 이후 운영 데이터는 공통 인증·인가를 적용한 단일 Supabase에 저장하며 로컬 저장으로 자동 전환하지 않는 방향입니다.

코르크와 겹친 포스트잇은 기존 표현을 검토하기 위한 최소 이식입니다. 모바일에서 제목이 가려질 수 있으며 키보드로 선택하거나 카드의 보이는 부분을 누르면 상세를 확인할 수 있습니다. 최종 목록/보드 구성과 접근성 개선은 후속 설계에서 결정합니다.

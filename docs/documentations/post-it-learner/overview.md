# 포스트잇 러너

포스트잇 러너에서 배운 내용을 주제별로 정리하고 다시 찾을 수 있습니다.

## 개인 기록 작성

1. MIG DOT에 로그인해 내 앱의 **포스트잇 러너**를 엽니다. 일반 회원은 운영자에게 모듈 이용 권한을 받아야 합니다.
2. **새 학습 주제**에서 이름을 입력합니다. 설명과 썸네일은 선택 사항입니다. 썸네일은 **주제 수정**에서 교체하거나 제거할 수 있습니다.
3. 주제 보드의 왼쪽 위 **+**를 눌러 제목과 내용을 입력합니다. 태그와 사진 한 장은 선택 사항입니다.
4. 목록에서 포스트잇을 열어 읽거나 **포스트잇 수정**에서 내용을 바꿉니다. 삭제하려면 수정 화면에서 **삭제**와 **삭제 확인**을 선택합니다.

주제 안의 검색은 제목·내용·태그를 대상으로 합니다. 주제 또는 기록 상세 주소를 다시 열면 로그인한 본인의 기록을 불러옵니다.

## 저장과 접근 권한

기록은 Supabase에 저장됩니다. 같은 계정으로 다른 기기에 로그인하거나 **새로고침**을 눌러 최신 기록을 불러올 수 있습니다. 저장 실패 시 편집 화면에 입력을 유지합니다. 같은 기록을 다른 기기에서 먼저 수정했다면 최신 내용을 확인한 후 다시 저장 여부를 결정할 수 있습니다.

기록은 개인 소유이며 모듈 운영자도 타인의 기록을 조회할 수 없습니다. 첨부 사진은 JPG·PNG·WebP를 지원하며 브라우저에서 긴 변을 최대 960px로 줄여 JPEG로 저장합니다. Supabase 설정이 없는 개발 서버에서는 미리보기의 **기록 기능 체험하기**를 누르면 주제와 포스트잇을 작성할 수 있습니다. 체험 기록은 브라우저 메모리에만 보관하며 새로고침하면 초기화됩니다.

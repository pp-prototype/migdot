- 상태 로컬 구현·검증 진행. 원격 프로젝트 연결 정보 없음

## 결정

Google 한 가지와 Supabase Auth PKCE를 초기 로그인 방식으로 구현한다. 최초 계정 자동 운영자 승격과 클라이언트의 역할 메타데이터 신뢰를 금지한다. 운영자가 직접 첫 owner를 지정하고 일반 사용자를 승인한 뒤 모듈을 허용한다.

공통 로그인, 모듈 이용 권한, 업무 데이터 소유권을 구분한다. 화면은 초기 확인·계정 변경·권한 오류 때 차단하고, DB는 live 권한 조회와 RLS를 사용한다. 현재 다섯 모듈은 restricted로 등록하고 메인·로그인·콜백은 공개 경로로 둔다.

운영자는 승인·모듈 허용/회수를 할 수 있으나 운영자 역할 변경은 관리 콘솔에서만 한다. 일반 계정은 스스로 가입하더라도 앱 승인이나 모듈 권한을 얻지 않는다. 승인 취소 시 모듈 권한을 삭제한다. 초대 이메일은 발송하지 않는다.

## 개발 환경과 검증

설정 없는 개발 서버만 명시적인 안내 아래 기존 예시 체험을 허용하고, 배포 빌드에서는 설정이 없으면 차단한다. 인증을 설정한 테스트 서버의 API 응답은 브라우저 테스트에서만 주입한다. PostgreSQL 설치 파일의 라이브러리 문제로 시스템을 변경하지 않고 PGlite 메모리 엔진에서 마이그레이션·RLS를 검증한다.

## 미완료와 후속 작업

실제 Google/Supabase 설정·첫 owner 지정·실계정 2개의 승인/회수 검증, 업무 데이터 테이블·Storage 정책, 비공개 문서 전달은 남아 있다. 정적 Markdown은 여전히 빌드 원본이며 라우트 제한을 원문 보호라고 설명하지 않는다. 원격 적용과 배포는 실행하지 않았다.

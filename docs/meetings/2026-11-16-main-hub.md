# 메인 허브 구성

- 논의일 2026-11-16 (Asia/Seoul)
- 근거 사용자의 메인 허브 및 네 페이지 구성 요청
- 상태 AI 작성 초안 · 개발자 검토 대기

## 배경과 목적

메인에서 모듈 앱을 찾고, 회의록·개발업데이트·문서를 각각의 주소에서 조회할 수 있도록 한다.

## 결정 사항과 근거

- `/`를 메인으로 사용하고 MIG DOT 제목과 이동 가능한 모듈 카드 목록을 표시한다.
- `/meetings`, `/updates`, `/documentations`를 개별 페이지로 제공한다.
- 문서 원본 폴더를 요청한 명칭에 맞춰 `docs/documentations/`로 통일한다.
- 기존의 단일 문서 탭 화면을 상단 메뉴의 개별 페이지로 변경한다.

## 후속 작업과 미해결 과제

첫 번째 개인용 앱 이식, 인증 및 배포는 후속 작업이다. 이번 범위에서 추가 보류·기각 사항은 없다.

# 익스큐셔너 최소 이식 결정

- 논의일 2026-11-16 (Asia/Seoul)
- 근거 사용자 ‘제안한 항목까지만 이식’ 요청
- 범위: 예시 오늘 화면, 과업/루틴 구분, 진행률, 28일 루틴 및 날짜별 과업 조회
- 상태 최소 이식 실행 · 실제 운영 기능은 보류

## 배경과 결정

선행 기능·디자인·서비스 검토의 최소 이식안을 구현한다. 사용자 데이터와 기존 서버를 연결하지 않고, 조회 가능한 미리보기로 제공한다. 필수 과업만 진행률에 포함하고 루틴 실천은 별도 표시한다.

날짜 계산과 핵심 정보 구조를 참고하고 MIG DOT 공통 색상·글자·카드 기준으로 화면을 구성한다. 별도 게임 헤더와 하단 메뉴를 가져오지 않고 ‘오늘/기록’을 모듈 상단의 URL 탐색으로 연결한다. 예시 날짜와 데이터임을 명확히 표시한다.

## 보류 및 후속 작업

실제 완료와 되돌리기·작성·수정·삭제·집중 실행·세션 복원·인증·인가·통합 Supabase·데이터 이관·PWA·오프라인 정책은 이번 범위에 포함하지 않는다. 원본의 수정/미추적 파일은 유지하며 소스의 사용자 데이터·환경 변수·DB에는 접근하지 않는다.

## 검증

공통 허브와 학습 모듈 회귀, 실행 화면의 진행률·날짜·루틴 선택·URL 복원, 저장소 불변·API 요청 없음, 모바일 화면을 검증한다. 결과는 개발 업데이트에 기록한다.

# 익스큐셔너 개인 기록과 자동 이월

- 일시: 2026-11-17 (Asia/Seoul)
- 근거: 로그인 사용자별 기능 논의와 사용자의 개발 착수 동의
- 합의: 미완료 자동 이월, 밀린 기간 인지, 마감 재열기, 시간 측정 제외

## 결정

자동 이월은 기존 과업을 오늘 목록에 이어 표시하며 최초 계획일을 덮어쓰거나 과업을 복제하지 않는다. 미접속 일수와 직접 일정 조정 횟수를 구분한다. 미래로 직접 조정한 과업은 예정일까지, 보류 과업은 복귀 전까지 이월하지 않는다. 루틴 미실천은 이월하지 않는다.

과업의 변경 시각과 상태 스냅샷을 서버에서 기록한다. 과거 날짜의 당일 결과는 이후 완료로 소급 개선하지 않고 이후 완료일을 별도로 연결한다. 당일 중 추가·취소·조정도 당시 대상과 상태에 포함하며 과업 수를 작업량으로 해석하지 않는다. 과거 회고는 다시 열어 수정하되 과업 완료를 소급 입력하지 않는다.

사용자 소유권과 현재 모듈 권한을 RPC와 RLS에서 모두 검사한다. 운영자는 다른 계정의 업무 기록을 열람하지 않는다. 쓰기는 사용자별 리비전을 잠그고 오래된 화면의 덮어쓰기를 거절한다. 저장 확인 후 성공 반응을 표시하며 응답 유실 시 입력을 남기고 재확인한다. 요청 ID로 같은 요청의 중복 처리를 방지한다.

## 근거와 검증 범위

목표 진행 점검 연구는 기록 가시화의 설계 근거이며, 자동 이월만으로 실행률이 높아진다는 증거로 취급하지 않는다. 누적 인지·재계획 도움·목록 부담을 실제 사용에서 확인할 가설로 유지한다.

## 보류와 운영 경계

타이머·알림·재화·AI 성향 분석·오프라인·기존 데이터 이관은 제외한다. 취소는 기록 보존이며 영구 삭제는 아니다. 첫 버전은 자신의 기록 전체와 이력을 조회하므로 장기 누적 후 데이터량과 조회 시간을 확인해 페이지 분할을 도입한다. 원격 마이그레이션과 실제 두 계정·두 기기 검증, 백업 복원 리허설은 운영 적용 시 별도 확인한다.

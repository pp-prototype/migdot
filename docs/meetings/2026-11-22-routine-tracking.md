# 루틴의 목적과 실천 피드백 개선

- 논의일 2026-11-22 (Asia/Seoul)
- 대상 익스큐셔너

기존에는 루틴 이름을 등록하고 일별로 체크할 수 있었다. 사용자는 반복하는 이유와 기대하는 변화를 정하고, 실천 여부와 달성 결과를 쉽게 확인하고 싶다고 요청했다.

과업 목록 위에 오늘의 루틴을 두고 등록과 실천 기록 버튼에 텍스트를 붙인다. 각 루틴에 목표와 기대 결과를 적으며, 목표 빈도는 오늘을 포함한 최근 7일 중 1~7일로 설정한다. 최근 7일 창과 실제 실천 기록을 사용하면 요일 설정 없이 기록 직후 진행을 확인할 수 있다.

미기록 수는 오늘 화면과 마감 창에서 알려준다. 최근 7일 목표에 도달하면 저장 직후 알리고 루틴 카드에도 달성 상태를 표시한다. 이번 변경은 앱 내부 피드백을 적용한다. 앱 외부 알림과 반복 요일 설정은 보류한다.

배포 시 익스큐셔너 루틴 목표 마이그레이션을 먼저 적용한다.

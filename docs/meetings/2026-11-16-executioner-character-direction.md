# 익스큐셔너 캐릭터 방향 구체화

- 상태 탐색 재량 승인 · 아래 구체 설정은 AI 제안이며 사용자 확정 전
- 범위: 캐릭터와 반응 원칙 문서화. 화면·코드·데이터·원본 앱 변경 없음

## 사용자 의도

게임 테마·게이미피케이션·단호한 처형인은 최초 아이디에이션의 출발점이다. 사용자 몰입과 경험에 도움이 된다면 성격과 표현은 달라질 수 있다. 이번 허용을 실제 몰입 효과가 검증됐다는 뜻으로 취급하지 않는다.

## 제안 정체성

이름은 익스큐셔너를 유지하고 역할은 ‘작은 과업에도 진지한 귀여운 집행관’으로 제안한다. 후드와 짧은 망토, 둥근 체형, 작은 도구에서 정체성을 유지한다. 집행 도구의 역할은 과업 완료 확인으로 표현하며 도장이나 종이 임무표 같은 소품을 검토한다. 구체 시각 디자인과 자산은 아직 제작하지 않는다.

단호함은 다음 행동의 명확함과 일관된 태도로 표현한다. 사용자의 성격이나 가치를 평가하지 않고 계획·실행·수정 가능한 선택을 확인한다. 웃음은 사소한 일에도 과하게 진지한 태도와 외형의 반전에서 만든다.

## 말투

짧고 건조한 문장에 가끔 반전 있는 한 줄을 사용한다. 모든 문장에 게임 용어를 반복하지 않는다. 버튼은 등록·시작·완료·일정 변경 등 동작이 분명한 이름으로 두고 대사에 세계관을 담는다. 사실이 없는 통계나 원인 추정은 대사로 만들지 않는다.

예시 대사는 시안이며 실제 기능 제공을 의미하지 않는다.

- 첫 진입: ‘오늘의 집행 목록을 확인하겠다.’
- 시작 준비: ‘한꺼번에 전부 할 필요는 없다. 첫 과업부터.’
- 작은 일 완료: ‘물 한 잔. 집행 완료. 중요한 임무였다.’
- 과업이 큼: ‘과업이 크군. 첫 행동부터 나누자.’
- 일정 조정: ‘계획이 바뀌었군. 목록을 다시 정리하지.’
- 하루 마감: ‘오늘의 집행은 여기까지. 남은 일은 다시 배치하자.’

## 상태와 화면 역할

초기 후보는 대기, 집중, 완료 확인, 하루 마감의 네 상태다. 불필요한 표정·애니메이션 수를 늘리지 않는다. 집중 실행과 마감이 실제 구현되기 전에는 해당 반응을 운영 동작처럼 보여주지 않는다.

캐릭터는 상단의 작은 상태 영역과 짧은 피드백에 사용하고 과업 목록·입력·타이머를 가리지 않는다. 입력이나 집중을 대사·연출로 중단시키지 않는다. 애니메이션 감소 설정을 존중하며 정보는 텍스트로도 제공한다. 완료 반응은 확인된 저장 결과와 연결한다.

## 게이미피케이션 범위

첫 단계는 오늘의 임무 확인 → 시작 → 완료 확인 → 하루 정리의 짧은 의식으로 구성할 것을 제안한다. ‘전체 과업 완료’와 ‘하루 마감’의 구별을 검토하고, 미완료에 대한 반응은 재계획으로 이어지게 한다. 귀환의 정확한 규칙은 미확정이다.

캐릭터 관리, 재화·상점·레벨·벌점·연속 접속 보상을 초기 필수 기능으로 추가하지 않는다. 이들은 실제 사용 결과가 필요성을 보여줄 때 검토한다.

## 다음 단계와 검증

정적 시안에서 오늘 화면, 완료 피드백, 하루 마감의 세 장면을 비교하는 방법을 제안한다. 캐릭터가 과업을 빨리 이해하고 시작하게 돕는지, 대사가 거슬리거나 평가받는 느낌을 주는지, 반복 사용 후에도 유효한지 관찰한다. 화면 시안 제작·자산 생성이나 실제 기능 개발은 이번 대화에서 실행하지 않았다.

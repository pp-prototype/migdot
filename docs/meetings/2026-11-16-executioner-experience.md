# 익스큐셔너 경험 구체화

- 논의일 2026-11-16 (Asia/Seoul)
- 근거 사용자가 원본을 서비스 아이디어로 보고, 제안한 기능·디자인을 원칙 안에서 과감하게 구체화하도록 요청
- 상태 AI 구현 판단으로 체험 시안 제작 · 영속 운영 기능은 미구현

## 결정과 근거

원본의 어두운 화면을 복제하지 않고 MIG DOT 공통 셸·탐색·접근성을 유지한 채 익스큐셔너 고유의 작은 세계를 구성한다. 짧은 망토와 후드·완료 도장을 든 귀여운 SVG 집행관, 과업 중심 목록, 짧은 대사, 첫 행동 안내 및 하루 마감을 구현한다.

기능은 계획 → 시작 → 완료/재계획 → 회고의 순환으로 구성한다. 전체 완료와 하루 마감은 구분하여 미완료가 있어도 마감할 수 있다. 캐릭터는 대기·실행·완료·휴식에 반응한다. 사실에 근거한 과업 수와 직접 쓴 회고만 보여주고 검증되지 않은 심리 평가나 가짜 AI 분석은 만들지 않는다.

## 영속 저장과 체험의 경계

공통 인증·인가·Supabase 테이블은 아직 없으므로 모든 변경을 React 메모리에서만 수행하고 초기화 조건을 화면에 표시한다. localStorage나 IndexedDB로 우회 저장하지 않는다. 새로고침·다른 모듈 이동은 초기화하고 오늘/기록 간에는 같은 모듈 상태를 유지한다. 운영 기능의 저장 성공과 캐릭터 반응을 연결하는 일은 실제 저장 기능 구현 시 완료 조건이다.

## 보류

실제 계정·클라우드 저장·집중 시간 측정·알림·PWA·오프라인 큐·기존 데이터 이관과 장기 행동 분석은 보류한다. 캐릭터 몰입 및 행동 개선 효과는 검증 전 가설이다. 이번 구현은 원본 프로젝트를 변경하지 않는다.

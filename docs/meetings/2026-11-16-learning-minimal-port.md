# 학습 모듈 최소 이식 범위

- 논의일 2026-11-16 (Asia/Seoul)
- 요청: 주요 기능 변경·개발에 앞서 최소한으로 이식 가능한 코드만 연결
- 상태 사용자 최소 이식 요청에 따른 구현 · 구체 범위는 AI 판단으로 제한

## 배경과 목적

기존 제안 대부분에 대한 사용자 동의를 바탕으로 첫 모듈을 MIG DOT 안에서 검토할 수 있게 한다. 확정되지 않은 인증·데이터 모델·최종 UX를 먼저 구현하지 않는다.

## 범위와 근거

고정 예시 데이터·보드 배치·기본 일러스트를 이식하고 학습 대상 목록, 보드, 상세, 검색과 URL 탐색을 연결한다. 공통 셸과 오류 경계·지연 로딩을 유지하며 스타일은 CSS Modules로 격리한다. 홈의 앱 등록과 기록 페이지 등록을 구분한다.

개인 데이터가 인증 없이 저장되거나 단일 클라우드 원칙을 우회하지 않도록 생성·삭제·업로드·로컬 저장·계정·동기화 코드는 가져오지 않는다. 원본 프로젝트와 그 데이터는 변경하지 않는다. 화면에 미리보기와 예시 데이터임을 표시한다.

## 보류 사항

공통 Auth/RLS/Storage, 테이블 마이그레이션, 실제 기록 이관, 작성·수정·삭제, 백업·복원, 최종 보드/목록 경험은 후속 작업이다. 보드의 겹침·질감은 확정된 디자인이 아니며 가독성과 접근성 개선 대상으로 남긴다.

## 검증

린트·타입 검사·프로덕션 빌드와 브라우저 테스트를 수행하고 사용 문서 및 개발 업데이트를 추가한다. 상세 결과는 개발 업데이트에 기록한다.

# 익스큐셔너 예약 푸시 설계

- 논의일 2026-11-22 (Asia/Seoul)
- 대상 익스큐셔너

## 배경과 대상

홈 화면에서 사용하는 웹 앱을 대상으로 한국 시간 오후 5시에 미완료 과업, 오후 9시에 미기록 루틴을 알려 달라는 요청이 있었다. 과업은 오늘 할 일과 이월된 열린 일을 포함한다. 루틴은 오늘 시작했거나 진행 중인 활성 루틴을 대상으로 한다.

## 결정 사항

앱이 화면에 떠 있지 않아도 동작하도록 Supabase Cron과 Edge Function이 Web Push를 보내고, 브라우저 서비스 워커가 알림을 표시한다. 운영체제 권한을 받은 기기만 구독하며, 예약 시점의 기록과 모듈 접근 권한으로 대상 여부를 판단한다. 잠금 화면에 표시할 내용에는 개인 기록 대신 남은 항목 수를 쓴다.

## 중복 방지와 후속 검증

같은 기기·날짜·알림 종류에 대해 발송 항목을 먼저 기록해 겹치는 예약 실행의 중복을 줄인다. 전송 결과가 불명확한 경우 자동 재시도는 보류한다. 운영 키와 예약 작업을 구성한 뒤 배포 도메인과 실제 iPhone·Android에서 홈 화면 수신을 확인한다.

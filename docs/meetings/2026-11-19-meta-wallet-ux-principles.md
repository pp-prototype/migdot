# 메타 월렛 UX 원칙 채택

- 논의일 2026-11-19 (Asia/Seoul)
- 주제 메타 월렛의 첫 방문과 반복 사용 UX를 공식 원칙에 반영

## 배경과 결정

사용자 검토에서 기존 결제 계산 흐름의 사용성이 낮았고, 오늘 쓸 돈을 보여주는 진한 카드 디자인은 유지할 가치가 있었다. 이후 논의에서 하루 생활비와 잔액을 함께 보여주고, 정확한 거래 입력 없이도 지출 추이를 볼 수 있는 일기와 날짜순 돈 계획을 채택했다.

## 사용 흐름과 계산 기준

첫 방문에는 오늘 기록을 바로 열어두고 잔액과 생활 기간은 점진적으로 받는다. 반복 사용 시 같은 홈에서 납부 일정과 지출 추이를 확인하며, 기록이 쌓이면 근거를 확인한 뒤 다음 계획에 반영한다. 계산에서는 확인 잔액, 일기, 예정 입출금을 구분한다.

## 후속 작업과 검증

계획 변경 이력과 카드 거래 연결은 후속 구현 범위로 기록한다. 사용자 테스트는 기록 횟수보다 첫 기록을 스스로 남기고 다음 계획 변경의 이유를 설명할 수 있는지를 확인한다.

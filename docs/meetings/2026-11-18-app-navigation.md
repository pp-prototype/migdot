# 이용 가능한 앱의 상단 내비게이션

- 논의일 2026-11-18 (Asia/Seoul)
- 기록 상태 AI 작성

## 결정 사항

기존 상단 헤더 아래에 앱 바로가기 영역을 배치하고 스크롤 시 화면 상단에 고정한다. 모바일에서도 앱 바로가기를 상단에 두고 공통 메뉴는 기존 하단 위치를 사용한다.

## 적용 기준

앱 탭은 공통 모듈 목록에서 접근 가능한 기능 앱만 가져온다. 표시할 앱이 없는 경우 탭 영역이 나타나지 않는다. 공통 브랜드 녹색을 배경으로 사용하고 흰색 글자, 현재 앱 밑줄, 키보드 포커스 테두리로 이동 상태를 표시한다.

# DB 없는 개발 화면과 앱 메뉴 확인

- 논의일 2026-11-22 (Asia/Seoul)
- 대상 공통 셸과 개발 환경

사용자는 데이터베이스에 쓰지 않고 기능과 로그인 후의 내비게이션을 검토할 개발 화면을 원했다. 익스큐셔너의 메모리 체험은 이미 등록·수정·체크·회고를 페이지 상태에 반영한다. 개인 클라우드 루틴 편집 기능과 테스트는 별도 경로에 있다.

기존 개발 명령을 보존하고 Supabase를 연결하지 않는 명시적 명령을 추가하기로 했다. 앱 메뉴는 현재 브랜치에 빠져 있던 기존 구현을 적용하고, 실계정 없이도 배치와 진입 전환을 확인할 수 있도록 했다. 실제 로그인에서 메뉴에 표시할 앱은 기존 권한 검사로 결정한다.

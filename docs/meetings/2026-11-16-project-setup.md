## 배경과 목적

여러 개인용 앱을 MIG DOT로 통합하기 위해 개발 가능한 최소 기반을 구성한다.

## 검토 및 결정

- README에 지정된 React, TypeScript, Vite, Tailwind CSS, React Router, Supabase를 사용한다.
- 단일 앱 내 모듈 등록, 지연 로딩, 오류 경계로 기능별 경계를 만든다.
- Markdown은 빌드 시 수집하여 문서 조회와 로컬 검색에 사용한다. 별도 문서 DB는 도입하지 않는다.
- 설정값이 없어도 앱 셸과 개발 문서를 열 수 있도록 Supabase 클라이언트는 선택적으로 초기화한다.
- 이번 작업은 로컬 개발 기반 구성으로 한정한다. 외부 서비스 생성 및 배포는 진행하지 않는다.

## 보류 사항과 후속 작업

- 첫 번째 이식 대상 앱 선정 및 데이터 구조 검토
- 공통 인증, 사용자별 RLS 정책, 백업·복원 절차
- Documentation 계층형 탐색과 관련 모듈 연결
- Cloudflare Pages 실제 배포 및 복구 절차 검증

위 항목의 세부 설계는 아직 결정되지 않았다. 접근할 수 없는 과거 대화는 이 기록에 포함하지 않았다.
